# Instanct Landing

Marketing site for Instanct, the professional discovery and connection platform.

## Getting Started

Install from the monorepo root with pnpm, then run the development server:

```bash
pnpm install --ignore-scripts
pnpm --filter instanct-landing dev
```

Open [http://localhost:3002](http://localhost:3002) to view the landing page.

Copy `.env.example` to `.env` to configure store links, the web app URL, contact email, and the API base URL used to load legal pages.
