# AI Coding Rules

## Goal

Build reliable, maintainable software with minimal wasted effort.

## Before coding

- Inspect the existing codebase before making changes.
- Identify the framework, package manager, architecture, and test commands.
- Understand the relevant files and dependencies.
- Ask questions only when a missing detail blocks progress.

## While coding

- Implement only what the current task requires.
- Reuse existing components, utilities, and patterns.
- Avoid unnecessary dependencies, rewrites, and abstractions unless the prompts said so.
- Keep changes small and focused.
- Never replace real functionality with mock data unless requested.
